# BranchDB v0.1.0-beta.1

First public developer beta: independently writable database branches inside a
modified PostgreSQL 20devel engine, sharing unchanged row storage in one server.

## Try it

Download the archive and its `.sha256` file for macOS ARM64 or Linux x86_64.
Verify the checksum, extract, then run:

```sh
./branchdb/bin/branchdb verify
./branchdb/demo.sh ./branchdb
```

The archive includes PostgreSQL, Python, CLI, bootstrap SQL, licenses, and an
isolation demo. No system PostgreSQL or Python is required. The demo changes
main and one child independently and verifies the other child retains its forked
value, then removes its own temporary instance.

## Included

- Branch creation, listing, deletion, and separate migration/application URLs.
- SCRAM authentication and branch-bound non-superuser roles.
- Tested Prisma 6.19.0 and Django 5.2.8 workflows.
- Core regressions, native suites, relocation/lifecycle/framework acceptance,
  and Linux container acceptance in the release workflow.
- Per-file manifests, source/engine hashes, archive checksums, and dependency notices.

## Boundaries

Developer beta for disposable data. READ COMMITTED and the documented SQL subset
only. No nested branches, merging, or upgrade/import path. Instances are bound
to the exact engine build. Scans, first writes, memory consumption, and maintenance
locks remain significant limitations. macOS is Apple Silicon only and binaries
are ad-hoc signed, not notarized; Linux is x86_64/glibc. Consult each archive's
manifest for OS requirements.

Read the repository's `docs/compatibility.md` and `docs/benchmarks.md` before
choosing a workload. This is an independent PostgreSQL fork, not an official release.
